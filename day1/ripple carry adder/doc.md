# 4-Bit Ripple Carry Adder Using Verilog HDL

## Aim

To design and simulate a 4-bit Ripple Carry Adder (RCA) using Verilog HDL and verify its operation through simulation.

## Theory

A Ripple Carry Adder is a combinational circuit used to add two binary numbers. It consists of multiple Full Adders connected in series, where the carry output of one Full Adder becomes the carry input of the next Full Adder.

In a 4-bit Ripple Carry Adder:

* Four Full Adders are connected in cascade.
* Two 4-bit binary numbers are added.
* Carry propagates from the least significant bit (LSB) to the most significant bit (MSB).
* The final carry generated is the carry output of the adder.

The term "Ripple Carry" comes from the fact that the carry signal ripples through each stage before the final result is obtained.

## Inputs and Outputs

### Inputs

| Signal | Description               |
| ------ | ------------------------- |
| A[3:0] | First 4-bit input number  |
| B[3:0] | Second 4-bit input number |
| Cin    | Initial carry input       |

### Outputs

| Signal   | Description        |
| -------- | ------------------ |
| Sum[3:0] | 4-bit sum output   |
| Cout     | Final carry output |

## Operation

### Step 1

The least significant bits A0 and B0 are added along with the carry input Cin.

### Step 2

The generated carry is passed to the next Full Adder stage.

### Step 3

Each subsequent Full Adder adds the corresponding input bits and incoming carry.

### Step 4

The process continues until the most significant bit is added.

### Step 5

The carry generated by the final Full Adder becomes the overall carry output.

5. Verify the Sum and Carry outputs.
